# Working with CRS and Projections in Python

This repository contains a notebook to explore CRS and map projections in Python. This is part of the course on [Advanced Geospatial Analytics with Python](https://hamedalemo.github.io/advanced-geo-python/intro.html) taught since Fall 2023 at Clark University. 


## Requirements

You need to use Pixi to install the local environment and run the notebooks in this repository.


## Instructions

```
pixi run jupyter lab
```

- If Jupyter Lab doesn't open automatically, copy the Jupyter Lab url and paste it in your browser. 
- Open `notebook/crs_and_projections.ipynb` and follow the instructions.
